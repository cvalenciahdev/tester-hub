# Tester Hub

Base del proyecto con Next.js, TypeScript y App Router.

## Arranque local

Instala las dependencias y ejecuta el servidor de desarrollo:

```bash
npm install
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000).

Las variables de entorno para la futura integración con Supabase están listadas
en `.env.example`. No es necesario configurarlas para arrancar esta base.
